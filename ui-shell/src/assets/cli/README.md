# CLI identity icons

These SVGs identify the installed providers in Copperbench. They are bundled locally; the interface does not fetch brand images at runtime.

| Local file | Source |
| --- | --- |
| `codex.svg` | `@lobehub/icons-static-svg` 1.95.1, `icons/codex.svg` |
| `claude.svg` | Same package, `icons/claudecode-color.svg` (Claude Code's mascot) |
| `grok.svg` | Same package, `icons/grok.svg` |
| `deepseek.svg` | Same package, `icons/deepseek-color.svg` |
| `antigravity.svg` | [Google Antigravity press assets](https://antigravity.google/press), [full-color SVG](https://antigravity.google/assets/image/brand/antigravity-icon__full-color.svg) |

LobeHub sources: [repository](https://github.com/lobehub/lobe-icons), [pinned package](https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.95.1). Its MIT license is retained in `LICENSE.lobe-icons` and the four SVGs. Brand marks belong to their respective owners. Only the black Codex/Grok marks invert in dark mode; colored artwork is unchanged.
