# NeoForge 26.3 structured item slice

This sample supplies independent test-host source and resources. The item itself is created and edited through the Native API by [structured_263_item_delivery.py](../../../sdk/python/structured_263_item_delivery.py), then generated by the NeoForge 26.3 plugin. No handwritten mod implementation is copied into the workspace.

The development manifest [required-cases.json](required-cases.json) freezes T01/T02/T05/T06 under `camp-kit-item-v1`, minimum 4, SHA-256 `b4963b6ad6f001d6f421383af5f352da9c6555f227b7b651f1c297117c8e2ff5`. It does not replace either published six-case Native or thirteen-case scoped-support gate.

| Input | Meaning and bounds |
| --- | --- |
| `displayName` | Generated item language entry; item identifier `name` remains immutable after creation. |
| `description` | Persisted creator metadata. |
| `stackSize` / `maxStackSize` | Integer 1–99, default 64; both aliases must agree. Sample uses 16. |
| `texture` | `minecraft:barrier`, `minecraft:stick`, `minecraft:coal`, or `minecraft:paper`; default barrier. |
| `rarity` | `COMMON`, `UNCOMMON`, `RARE`, `EPIC`; default COMMON. |
| `immuneToFire` | Boolean, default false. |
| `fuelBurnTime` | Integer 0–128000 ticks; 0 omits the cooking-fuel component. Speed multiplier is fixed at 1. |
| `compostingLayers` | Integer 0–7 layers per consumed item; 0 omits the compostable component. This is a constant layer count, not the older probability field. |

Call `get_mod_element_field_contract` for the active generator before writing. Use the separately negotiated `preview_targets/1` extension and explicitly opt in for each new product session. Creation and updates of other structured types or fields remain rejected. The normal permission, revision, source ownership and task-authorization checks still apply.

The [host tests](src/gametest/java/copperbench/acceptance/AcceptanceTests.java) check registration/stack size, default components plus a saved component patch, packaged display-name localization, real furnace fuel consumption and expiry, and deterministic composter world-state changes. They execute against the generated JAR in an independent server host. Player input and rendering are verified by the later client tickets.

On Windows, from the repository root with the qualified Gradle cache:

```powershell
pwsh -NoProfile -File scripts/run-gradle-external.ps1 runStructured263ItemDelivery '-Pp263Generator=neoforge-26.3' '-Pp263GradleHome=C:/Users/Administrator/.gradle' --no-daemon --console=plain
```

This opt-in local acceptance runner creates a separate workspace and scoped temporary authority, and revokes that authority when it finishes. It records creation, protected Native writes, input rejections, generation, build, the four-case run, export and new-process reopen under `output/p263-15/native`. It uses existing qualified dependencies; it does not claim a cold-cache or installed-product result.
