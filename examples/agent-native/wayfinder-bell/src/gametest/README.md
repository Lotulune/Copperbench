# Copperbench GameTests

The starter checks mod loading only. Add tests for your own behavior before treating this as gameplay acceptance.

Copperbench builds a frozen copy of the real workspace, loads its packaged JAR in a separate host, and reports actual test counts and source/JAR hashes.
Edit the test sources here and use run_gametest or headless run-gametest. The runtime writes no player world to your original workspace.
