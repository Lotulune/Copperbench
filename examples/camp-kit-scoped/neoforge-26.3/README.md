# Integrated scoped Camp Kit fixture

This fixture runs T01–T13 against one structured, generated mod JAR. The Native SDK
creates item, block, recipe, function and code elements through their bounded
contracts. The host imports no generated implementation constants or source.

The shared Trail Kit has a 16-item stack, rare/fire-resistant components, a
200-tick fuel component and one compost layer. Recipe tests use that same item
and independently expect the 200-tick fuel budget. Recipe and loot reloads are
serialized on the server executor and retain both selected datapacks. The
function's position (12,80,12) is separate from the saved pillar at (8,80,8).

This is a qualification input, not a passed G2 or published support claim.
Installation, actual player operations, same-world reopening and legacy exact
generator regressions must be bound to a newly frozen candidate.
