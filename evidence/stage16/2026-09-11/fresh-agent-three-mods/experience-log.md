## 开发修正与介入统计

- 本机用户实际授权 1 次；本 agent 点击审批 0 次、伪造授权 0 次。授权覆盖试验根目录，修复后未再次申请。
- 父任务进行了 2 轮产品修复和新候选交付；没有人为编写或修改本轮模组 Java。
- 初稿按官方 Yarn 文档独立编写，随后从真实 `build.gradle` 发现 Mojang 映射，并按本轮工程 Minecraft 依赖调整。`environment` 未直接显示映射方案，这增加了发现成本。
- 测试夹具修正重跑 1 次。Minecraft 自带 `makeMockServerPlayerInLevel()` 的匿名类将 `isCreative()` 固定为 true；首次计数石结果虽为 5/5，仍被标为 superseded。改用正常 ServerPlayer 并断言实际游戏模式后，重新得到最终 5/5。旧结果和源码快照保留，不重复计入最终用例。
- 实际 GameTest 总执行数为 22，最终认可的不同用例数为 17；没有失败/跳过用例、没有将原版自检当验收。Java 编译失败修复次数为 0。

本 agent 只读取公开文档、打包产品公开接口以及新建工程/自身草稿。为核对符号和测试玩家行为，仅对新建工程暴露的 Minecraft 依赖运行 `javap`；未读 Copperbench 源码、旧样例、旧试验报告或其他 agent 实现，未使用产品内部类路径，未手动调用编译器或 Gradle，未修改用户配置，未提交或推送 Git。产品输出的 `JAVA_TOOL_OPTIONS` 行原样保留；调用脚本没有设置环境覆盖。最终验收后未再启动重型进程。

物品 codec、Minecraft 区块磁盘读回和实际 SavedData 文件读回已经验证。完整进程/世界重启、客户端 actionbar 可见性、客户端真实输入仍未由本 agent 验证。父任务最后报告 Windows 锁屏导致桌面输入门禁待处理；该状态没有影响本报告中的服务端测试，也不作为客户端通过证据。
