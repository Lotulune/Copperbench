# 阶段 2：版本历史、MCP 与 headless

- 状态：已完成（2026-08-17 本机 G3 门禁通过）
- 依赖：阶段 1
- 对应门禁：G3，部分 G6

## 目标

建立 AI 友好的正式控制面、不可绕过的恢复机制和无界面自动化入口。

## 范围

- 使用 JGit 实现版本、比较、恢复点和还原领域服务。
- 兼容已有 Git 工作区，不覆盖远程、分支或用户提交历史。
- 集成官方 MCP Java SDK，提供本机 Streamable HTTP。
- 实现 Read Only、Workspace、Full Access 三档权限与受保护操作。
- 实现工作区短期令牌、严格来源控制、日志脱敏和令牌吊销。
- 提供 `build`、`validate`、`export` headless 命令框架、JSON 输出和退出码。
- 提供第一批领域工具：工作区信息、元素列表、元素读取、元素变更预览、校验和恢复点。

## 不在范围

- 远程或局域网 MCP。
- 内置 AI 对话面板。
- 外部平台发布。
- 启用 Java 插件的 AI 工具。

## 交付物

- Local History 服务及可恢复事务测试。
- MCP 工具 Schema、工具目录与兼容策略；UI-Core 保持 `0.1`，在阶段 3 纵向链路完成后冻结 `1.0`。
- 三档权限策略引擎和受保护操作审计。
- headless 命令契约、帮助和机器可读错误格式。
- MCP Inspector/官方一致性测试结果。
- UI 权限与历史页面所需 fixtures。

## 关键任务

1. 明确已有根 Git 仓库与上游 `.mcreator/localHistory` 的处理规则。
2. 每个变更工具映射到阶段 1 应用命令，不直接编辑 `.mod.json`。
3. 在 Read Only 下将有写副作用的校验隔离到临时快照。
4. 测试恶意网页访问 localhost、过期令牌和跨工作区令牌。
5. 为长任务提供取消、日志流、结果状态和进程清理。

## UI 并行工作

完成权限选择、操作审批、历史时间线、差异查看和长任务状态的 React 原型。只接模拟桥接，不接真实文件系统。

## 风险

- 本地 Git 与用户已有工作流冲突。缓解：检测并复用现有仓库，所有历史改写操作需明确确认。
- MCP SDK JSON 依赖污染核心。缓解：隔离 Jackson，仅在 MCP 模块转换 DTO。
- YOLO 被误解为关闭审计。缓解：策略层强制恢复点、日志和受保护确认。

## 退出条件

- [x] G3 全部通过。
- [x] 失败的 AI 变更可从恢复点恢复，且操作日志可追溯。
- [x] 无令牌客户端无法列出或调用 MCP 工具。
- [x] headless 与桌面适配器对同一命令得到一致结果。
- [x] Java 插件不能由 AI 静默启用。
