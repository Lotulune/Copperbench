# 阶段 7：版本轨道与加载器迁移

- 状态：G6 与 1.21.1 G2 已通过；轨道已校准为 26.2 / 26.1 / 1.21.1 / 1.20.1。四轨均有第一方纵向生成；26.2 / 26.1 / 1.20.1 编译仍门禁。阶段 7 领域退出条件已按诚实证据关闭。
- 依赖：阶段 5、阶段 6
- 对应门禁：G2、G6

## 目标

从 1.21.1 纵向验证扩展为正式四轨产品，并提供诚实、复制式、可诊断的 Fabric/NeoForge 迁移。

## 范围

- 为最新稳定版、前一个稳定版、1.21.1 和 1.20.1 建立生成器包与状态元数据。
- 每个版本分别维护 Fabric 与 NeoForge 状态和能力矩阵。
- 动态两轨承载完整新功能；固定两轨承载构建兼容、严重修复和评估后的回移。
- 实现上游 MCreator 工作区迁入、备份和报告。
- 实现 Loader Migration：从源工作区创建目标副本，转换通用字段和已知扩展。
- 报告支持、替代、信息丢失、阻断和人工处理项。
- UI/MCP/headless 提供预览、执行、校验和比较，但不默认替换源工作区。

## 不在范围

- 无损双向同步。
- 一个工作区同时维护两套活动生成器。
- 自动删除或归档源工作区。
- 对所有第三方插件元素进行通用迁移。

## 交付物

- 四轨双加载器支持矩阵和发布状态源。
- 每轨黄金工作区、生成/编译证据和依赖清单。
- Workspace Migration Schema 与转换注册表。
- Loader Migration 预览与执行服务。
- 迁移报告 UI、MCP 资源和 headless JSON 输出。
- 固定版本维护与退役流程。

## 迁移原则

- 源工作区只读，所有结果写入新目录。
- 开始前记录源哈希和恢复信息。
- 不理解的字段保留在报告或命名空间数据中，不能静默丢弃。
- 目标构建失败不代表迁移完成。
- 重复执行相同迁移应产生等价结果。

## 风险

- 四轨维护成本高于功能开发速度。缓解：共享领域测试，模板差异显式化，固定轨限制回移。
- 动态最新版加载器发布时间不同。缓解：分别标记状态，Fabric 可先稳定，NeoForge最多晚一个里程碑。
- 第三方插件元素不可迁移。缓解：插件提供迁移扩展点，缺失时阻断或保留原始数据。
