# 阶段 3：Fabric 1.21.1 端到端链路

- 状态：进行中（2026-08-17 G2/G3 已通过；真实 JCEF UI 组合待 U2）
- 依赖：阶段 2
- 对应门禁：G2（Fabric 1.21.1 子集）、G3

## 目标

用一个稳定版本证明完整产品链路，而不是先铺开大量未闭环的编辑器。完成创建、编辑、生成、构建、测试、AI 操作和回滚。

## 范围

- 固定并内置 Fabric 1.21.1 生成器来源。
- 建立 Fabric 能力清单和与 NeoForge 上游定义的差异。
- 支持工作区、方块、物品、配方、简单 Procedure、纹理和语言条目的纵向样例。
- 提供创建、读取、更新、删除、生成、构建和运行客户端的领域命令与 MCP 工具。
- 建立黄金工作区、生成文件快照、编译测试和 Minecraft 客户端启动烟雾测试。
- 验证恢复点、差异、还原和再次构建。

## 不在范围

- 所有模组元素类型。
- 动态最新版本和 1.20.1。
- NeoForge 正式对齐。
- 完整 Blockbench 往返。

## 端到端验收场景

1. 创建 Fabric 1.21.1 工作区。
2. 创建带纹理和本地化名称的方块与物品。
3. 创建配方和一个简单 Procedure。
4. 通过 MCP 修改属性并运行校验。
5. 生成并编译模组，启动测试客户端。
6. 创建版本，执行破坏性修改并从恢复点还原。
7. 再次构建，证明结果可复现。

## 交付物

- 第一方 Fabric 1.21.1 生成器模块。
- 纵向元素领域合同与 MCP 工具。
- 黄金工作区和生成快照。
- 编译、运行客户端和日志诊断证据。
- Fabric 缺失能力与后续补齐清单。
- 供阶段 4 正式 UI 接入的稳定 Schema v1。

## 风险

- 社区生成器继承 NeoForge 模板导致隐式耦合。缓解：建立来源追踪和差异测试，不进行无来源复制。
- Minecraft 客户端烟雾测试不稳定。缓解：区分编译门禁和运行门禁，捕获固定日志标志。
- 简单样例不能暴露复杂 Procedure 问题。缓解：此阶段只证明架构链路，后续扩大黄金样例。

## 退出条件

- [ ] 端到端场景可由人工 UI、MCP 和 headless 组合重复执行（Mock UI、MCP、headless 已通过；真实 JCEF UI 待 U2 接线）。
- [x] Fabric 1.21.1 黄金工作区生成和编译稳定通过。
- [x] 客户端启动并加载测试模组的证据可自动采集。
- [x] 回滚后工作区和生成结果恢复一致。
- [x] 阶段 4 所需 UI 合同冻结为兼容的 v1。
