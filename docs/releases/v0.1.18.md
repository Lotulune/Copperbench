# Copperbench 0.1.18 — Windows

0.1.18 新增模型与元素预览、专业工作台 Agent，并修复 Blockbench 打开与保存同步。

- 直接预览 Minecraft JSON、OBJ/MTL、Blockbench 模型和常见 Java 实体导出的静态几何，支持旋转、平移、缩放及元素草稿外观。
- 专业工作台可使用 Agent，与简洁版共享会话；支持附件、源码/日志上下文、模型与思考强度、会话权限、修改差异、独立 Core 验证、取消及历史管理。
- Blockbench 准备恢复点期间仍可浏览工作区；离开资产页后保存并退出编辑器，修改仍会同步。关闭工作区时会阻止尚未完成的编辑器启动。
- 修复窄窗口导航与 Agent 入口布局，保留键盘操作和可访问名称。

**English:** This release adds static model and element previews, brings the shared Agent workflow into the professional workbench, and keeps workspace browsing and saved-model synchronization responsive during Blockbench editing.

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用同一 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。签名源码标签为 `v0.1.18`；准确提交、文件摘要和构建来源见 `RELEASE-METADATA.json` 及 GitHub provenance。

预览显示静态几何与默认姿态，不执行任意 Java，也不模拟游戏动画或完整光照。首次为大型工作区建立恢复点仍可能需要等待。Blockbench 与创作 CLI 单独安装和配置。源码回归、真实 Windows JCEF/Codex/Blockbench 验证及正式包记录见[本轮发布记录](../testing/maintenance-release-0.1.18.md)。生成器支持与开发预览范围沿用随包 `product-status.json`。

Linux 使用独立的 [0.1.18 发布说明](v0.1.18-linux.md)，公开下载以[当前下载](current.md)为准。
