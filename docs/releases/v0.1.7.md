# Copperbench 0.1.7 — Windows

0.1.7 修复近期交付流程中的两个导出问题：

- 数据包工作区的默认交付文件改为 `.zip`；重新生成交付路径时也保留正确格式。此前数据包沿用 `mod` 工作区类型而得到 `.jar`，导致后端拒绝导出。
- 普通模组导出直接验证本次 Gradle 归档回执。归档位于自定义 `build` 子目录时，不再额外要求存在 `build/libs`；仍核对 JAR 摘要并保护已有文件。

Windows 11 x64 提供 EXE、便携 ZIP 和 MSIX。请使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包沿用现有 Authenticode 未签名分发方式。

修复范围与实际验证记录见[0.1.7 发布记录](../testing/maintenance-release-0.1.7.md)。自动化检查覆盖交付逻辑与浏览器交互；本版未新增完整图形安装、Minecraft 玩家操作或同世界重开验收结论。
