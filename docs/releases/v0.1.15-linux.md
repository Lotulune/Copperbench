# Copperbench 0.1.15 — Linux x86_64

0.1.15 新增简洁创作与专业工作台切换，并改进任务、语言切换和弹窗操作。

- 简洁界面接入主机安装的 Codex CLI、Claude Code、Grok Build、Antigravity CLI 和 DeepSeek Harness，提供图标、聊天历史、授权和澄清问题。CLI 使用主机现有配置与登录状态。
- 新建作品支持原生文件与目录选择；恢复点、试玩和导出沿用现有工作区流程，切换模式保留草稿和任务。
- 修复聊天与编辑草稿保护、重复新建表单、任务入口和日志跟随行为。
- 改善即时翻译、叠加弹窗焦点、MCP 配对恢复，以及原生按钮和进度显示。

面向 Ubuntu 24.04 LTS x86_64，提供图形安装 Setup.tar.gz、Debian .deb、便携 .tar.gz 和应用内更新组件。使用同一 Release 的 `linux-candidate-sha256.txt` 校验下载。

Linux 发布由签名标签 `v0.1.15-linux-stable` 标识，直接发布通过独立消费者验证的冻结候选文件，发布时不重新构建二进制。确切源码、候选工作流和资产哈希见 `LINUX-CANDIDATE-METADATA.json` 与 `LINUX-RELEASE-AUTHORIZATION.json`。完整 GNOME 安装、升级、卸载、屏幕阅读器和玩家操作验收未重新执行，`formalSupportClaim` 保持 `false`；生成器支持与开发预览范围沿用对应包的声明。

Windows 说明见 [0.1.15](v0.1.15.md)，各平台公开下载以[当前下载](current.md)为准。
