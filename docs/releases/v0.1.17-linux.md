# Copperbench 0.1.17 — Linux x86_64

本版本包含[Windows 0.1.17 说明](v0.1.17.md)中的旧会话原位续聊、附件错误语言切换、截断消息的附件回收及窄窗口模式名称修复。

**English:** Linux ships the same conversation, attachment lifecycle and compact-layout maintenance fixes. Release assets are promoted from the independently verified frozen main candidate without rebuilding.

目标平台为 Ubuntu 24.04 LTS x86_64，提供图形安装 Setup.tar.gz、Debian .deb、便携 .tar.gz 和应用内更新组件。使用同一 Release 的 `linux-candidate-sha256.txt` 核对下载；安装步骤见[中文](../user/linux-installation.md)或[English](../user/linux-installation.en.md)。

Linux 使用独立的固定候选发布流程：平台与生成器回归、包内容和文件权限、随包启动、安装器渲染、JCEF 与 Fabric/NeoForge X11 渲染、独立消费者核验、来源证明及完整草稿下载比对。具体结果见[本轮发布记录](../testing/maintenance-release-0.1.17.md)及发布载荷中的 `LINUX-RELEASE-AUTHORIZATION.json`。

本轮不扩大完整 GNOME/Wayland 安装、升级、卸载、真实 CLI 账号或玩家操作认证，`formalSupportClaim=false`。历史验收保留原来源与范围。各平台公开状态以[当前下载](current.md)为准。
