# Copperbench 0.1.6 — Linux x86_64

Linux 0.1.6 正在准备发布，产品改动与 [Windows 0.1.6](v0.1.6.md)一致，包括首作引导、草稿恢复、诊断定位、普通与精确交付、Native SDK 生命周期和双语路线文档。当前公开下载仍为 [0.1.5](current.md)。

## 安装

计划提供 Debian `.deb`、便携 `.tar.gz` 和图形安装向导 `Setup.tar.gz`，内置 JBR 25／JCEF 与独立 Java 21。目标环境保持 Ubuntu 24.04 LTS x86_64；其他发行版与架构保留未验证状态。

图形安装包解压后运行 `Install Copperbench`；便携版运行 `copperbench.sh`。Debian 包发布后可使用：

```sh
sudo apt install ./copperbench_0.1.6_amd64.deb
```

安装与设置见[Linux 安装说明](../user/linux-installation.md)。首次构建需要联网，Blockbench 单独安装。下载校验使用新 Release 自己的 `linux-candidate-sha256.txt`。

## 来源与验收范围

Linux 发布沿用冻结候选路径：成功的主线 push 候选、原始 `LINUX-CANDIDATE-METADATA.json`、包摘要与来源证明、该候选专属授权，以及下载后的草稿字节比较。候选源码、运行编号、哈希和授权在真实构建后记录，不复用 0.1.5 的授权例外。

最终候选尚未产生。当前未新增最终 0.1.6 包的完整 GNOME Wayland/Xorg 安装、偏好迁移、Blockbench 往返、UI 持久化或 Minecraft 玩法验收。历史候选的无界面构建与交付、旧 VM 和游戏记录保留原来源与产物范围。实际进展见[发布准备记录](../testing/maintenance-release-0.1.6.md)。
