Linux 0.1.6 已按冻结候选晋级公开：[Linux 稳定版](https://github.com/Lotulune/Copperbench/releases/tag/v0.1.6-linux-stable)，发布于 `2026-10-15T16:17:00Z`。产品改动与 [Windows 0.1.6](v0.1.6.md)一致，包括首作引导、草稿恢复、诊断定位、普通与精确交付、Native SDK 生命周期及双语路线文档。

## 安装包

本版提供 Debian `.deb`、便携 `.tar.gz` 和图形安装向导 `Setup.tar.gz`，内置 JBR 25／JCEF 与独立 Java 21。目标环境保持 Ubuntu 24.04 LTS x86_64；其他发行版与架构未验证。

图形安装包解压运行 `Install Copperbench`，便携版运行 `copperbench.sh`。Debian 安装命令为：

```sh
sudo apt install ./copperbench_0.1.6_amd64.deb
```

安装与设置见[Linux 安装说明](../user/linux-installation.md)。首次构建需要联网，Blockbench 单独安装。校验使用同一新 Release 的 `linux-candidate-sha256.txt`。
