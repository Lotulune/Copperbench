# Copperbench 0.1.8 — Linux x86_64

0.1.8 修复启用 Gradle 配置缓存时模组导出失败的问题，覆盖 NeoForge 和自定义 Gradle 归档目录。导出任务保留现有项目配置和 JAR 摘要校验。

Ubuntu 24.04 LTS x86_64 提供 Setup.tar.gz、DEB 和便携 tar.gz。使用本 Release 的 `linux-candidate-sha256.txt` 校验下载。Linux 包通过冻结候选及签名来源证明晋级，桌面与玩家验收范围保持单独记录。

修复与验证进度见[0.1.8 发布记录](../testing/maintenance-release-0.1.8.md)。
