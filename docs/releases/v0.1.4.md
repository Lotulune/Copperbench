# Copperbench 0.1.4 — Windows

本次更新面向 Windows 11 x64，提供 EXE、便携 ZIP 和 MSIX。Linux 当前公开版本继续保持 0.1.3。

## 工作区与界面

- 简化 Product Shell 导航、概览和页面说明，收起低频工具；统一紧凑窗口、表单与列表的间距和对齐，保留键盘操作及清晰的操作状态。
- 新增源码工作区：浏览和搜索项目文件，在标签页中编辑手写文本文件，查看入口与注册位置并跳转到源码行。切换页面保留草稿，外部修改冲突保留本地内容，关闭窗口前检查未保存修改。生成器管理的文件保持只读。
- 新增关系图：查看 Mod Element、资产和未解析引用，支持搜索、展开、分页、平移、缩放以及打开相关内容。可拖动节点、使用键盘或方向按钮调整显示位置，并恢复默认布局；移动节点不会改动工作区数据。
- 资产页支持实际 PNG/JPEG 图片与模型 JSON、已解析纹理预览。不支持的格式会显示明确状态。
- 设置页提供主题、语言和源码编辑器偏好；“版本与迁移”直接展示 Minecraft 版本、加载器与支持状态，保留迁移预览、校验和必要确认。

## 可靠性与维护

- 源码保存检查 Workspace Revision 和文件哈希，遵循已有历史记录与事件流程；拒绝越界路径、链接和超出文本读取限制的文件。
- MCP 权限可直接选择并持久化；切换时使旧令牌和旧会话失效。SDK 收紧响应校验，只重试已审查的只读请求，避免自动重放写操作。
- 资源包导出与复制迁移统一文件边界检查；界面桥接修正任务事件乱序处理。
- CI 按改动范围选择检查，保留现有必需检查及夜间回归，减少重复 UI 构建；本次未给出未经测量的提速比例。

## 安装与验证范围

请使用同一 Release 附带的 `SHA256SUMS.txt` 核验安装包。Windows 安装包未做 Authenticode 签名，系统可能显示发布者或 SmartScreen 提示。首次构建需要联网，Blockbench 需单独安装。

本轮包含针对性 Java、契约与浏览器回归，以及开发工作区的实际界面检查。未重新执行 0.1.4 安装包的完整桌面验收或全量 Minecraft 游戏验收；历史版本的安装与玩法记录保持原版本范围。最终源码、CI 和打包结果见[发布验证记录](../testing/product-shell-release-0.1.4.md)。本次未发布 Linux 0.1.4，也未扩大平台或生成器支持范围。
