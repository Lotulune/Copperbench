# Copperbench 0.1.9 — Windows

0.1.9 修复云端验收发现的三类导出问题：

- NeoForge 等开启 Gradle 配置缓存的项目可正常导出模组，项目设置和普通构建保持原有行为。
- 1.20.1 数据包迁移旧版内置 Gradle 8.3 配置，使用与 Java 25 兼容的 Gradle 9.7；自定义配置保留。
- Windows 短路径别名与 Gradle 长路径正确对应，同一工作区内的 JAR 不再被误判越界；符号链接、外部路径和摘要检查保留。

Windows 11 x64 提供 EXE、便携 ZIP 和 MSIX。使用本 Release 的 `SHA256SUMS.txt` 校验下载，Windows 包保持 Authenticode 未签名分发。

0.1.8 在 Windows 发布测试阶段停止，没有发布正式二进制。修复与验证记录见[0.1.9 发布记录](../testing/maintenance-release-0.1.9.md)。
