# Copperbench 0.1.13 — Linux x86_64

Linux 0.1.13 正在准备发布，目标是与 Windows 0.1.13 同步产品源码版本。当前可下载的 Linux 稳定版仍为 0.1.9；本页不是发布完成或安装验收通过的声明。

目标平台沿用 Ubuntu 24.04 LTS x86_64，计划提供图形安装 `Setup.tar.gz`、Debian `.deb` 和便携 `.tar.gz`。正式发布后，使用同一 Release 的 `linux-candidate-sha256.txt` 校验下载。

0.1.13 的快捷方式保留、更新助手登记及权限提示改动主要针对 Windows。Linux 版本同步不代表增加了 Windows 专用更新能力，也不扩大生成器和发行版支持范围。

待核验的主线候选、冻结源码和发布前检查见 [Linux 0.1.13 准备记录](../testing/maintenance-linux-0.1.13.md)。签名来源、候选包摘要、独立下载校验及安装验收结果将在取得实际证据后记录；历史 0.1.9 的验收范围不会转记到本版。
