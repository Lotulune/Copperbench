# Copperbench 0.1.13 — Linux x86_64

Linux 0.1.13 将产品源码与 Windows 0.1.13 对齐，包含自 0.1.9 以来的共享桌面界面、图标、原生窗口及应用内更新改进。

- 启动画面跟随语言选择，首页重新安排工作区入口、最近项目和辅助工具。
- 「帮助与关于」提供手动检查更新入口，后台发现新版时显示更新按钮与目标版本。
- 提供 Linux 应用内更新清单和组件包，支持复用未变化的运行环境。
- 统一原生弹窗、安装器与进度窗口的主题和中英文提示，并改善长文本换行、滚动和紧凑布局。
- 保留 0.1.9 的 Gradle 配置缓存导出、归档路径与 1.20.1 数据包 wrapper 迁移修复。

Ubuntu 24.04 LTS x86_64 提供图形安装 `Setup.tar.gz`、Debian `.deb`、便携 `.tar.gz` 及应用内更新组件。使用同一 Release 的 `linux-candidate-sha256.txt` 校验下载。公开发布状态与下载入口以[当前下载页](current.md)为准。

冻结源码为 `464b75a39c34252f61c7d859b8d267dfabba205c`，候选来自主线运行 [39264954357](https://github.com/Lotulune/Copperbench/actions/runs/39264954357)。13 项候选 CI 门禁及独立消费者对 17 个文件的摘要、签名来源和包内内容核验通过，详见[候选授权与验证记录](../testing/maintenance-linux-0.1.13.md)。

本次维护发布未重复完整 GNOME 安装、升级、卸载及玩家操作验收，也不扩大生成器、发行版、架构或离线支持范围。Windows 专用的快捷方式与更新登记修复不作为 Linux 新能力宣传；历史 0.1.9 的验收记录保持原有范围。
