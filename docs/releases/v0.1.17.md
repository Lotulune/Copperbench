# Copperbench 0.1.17 — Windows

0.1.17 修复旧版会话续聊、附件状态与窄窗口显示问题。

- 旧会话未记录模型但保留原生 CLI 会话时，显示“沿用会话模型”，可直接继续原对话；不会偷偷换成当前默认模型。主动切换模型仍新建对话并转移草稿。
- 附件校验、上传、保存、选择及清理错误会随中英文切换即时更新，保留未发送输入。
- 超过 1,000 条消息后仍跟踪早期附件，供原生会话恢复读取；删除对话时回收不再被引用的副本并释放存储额度。
- 500×600 窄窗口完整显示两个模式名称，保留键盘、触屏、等宽按钮与减少动画行为。

**English:** This maintenance release restores in-place continuation of legacy CLI conversations without overriding their model, updates attachment errors when the UI language changes, retains cleanup ownership for attachments from truncated messages, and fixes narrow-window mode labels.

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用同一 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。签名源码标签为 `v0.1.17`；准确提交、文件摘要和构建来源见 `RELEASE-METADATA.json` 及 GitHub provenance。

[修复验证](../testing/assessment-0.1.16-fixes.md)包含真实旧版序列化代码比对、可控 CLI 子进程和浏览器回归。正式包构建与公开核验另见[发布记录](../testing/maintenance-release-0.1.17.md)。本轮未重新执行真实 CLI 账号的完整安装升级、Minecraft 玩家流程或新手研究；旧版本已失去全部引用的附件不会自动清扫。生成器与开发预览范围沿用随包 `product-status.json`。

Linux 使用独立的 [0.1.17 发布说明](v0.1.17-linux.md)，公开包以[当前下载](current.md)为准。
