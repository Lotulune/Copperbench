# Copperbench 0.1.5 — Windows

本次更新面向 Windows 11 x64，提供离线图形安装器 EXE、便携 ZIP 和 MSIX。对应源码由签名标签 `v0.1.5` 和同一 Release 的 `RELEASE-METADATA.json` 标识。

## 首次创作与诊断

- 创建请求缺少字段或输入类型不正确时，返回字段路径、期望类型和修复提示；创建弹窗显示具体诊断并保留输入，失败后工作区保持完整。
- 新增[第一件作品教程](../user/first-creation.md)，从选择生成器、创建步道方块到构建、取得和放置方块、保存重进，给出具体输入与预期结果。
- 统一 Agent、About 和公开指南的生成器说明；[状态总览](../status.md)区分下载版、源码新增、预览与未验证范围。
- 更新 `source-map-js`、`undici` 和 `fast-uri` 的依赖锁项，修复本轮 npm 审计发现的三个 high 告警。来源、影响和审计范围见[依赖记录](../../compliance/dependency-audit/2026-10-14.json)。

## 编辑器与生成器修复

- 保存后的延迟刷新不再覆盖新草稿；数字输入保留负号、小数和未完成的编辑状态，有效数值在提交时转换。
- 修复工具、生物和特殊实体的创建默认值及贴图诊断，开放方块的 `luminance` 与 `lightOpacity` 字段。
- 修复 Fabric 1.21.1 的刷怪蛋、剪羊毛及船实体渲染模板，解决放置或重新载入自定义船时的崩溃；普通船、箱子船、竹筏与箱子竹筏均有生成和编译回归。
- 包含自 0.1.4 后合入的项目加载、关系图交互及原生工作区维护修复。

## 安装

- Windows 离线安装向导支持简体中文和 English，保留当前用户／系统范围、升级及卸载流程；应用首启和 Blockbench 设置同步双语说明。
- 使用同一 Release 的 `SHA256SUMS.txt` 校验文件。安装包未做 Authenticode 签名，Windows 可能显示发布者或 SmartScreen 提示。
- 首次构建需要联网；Blockbench 单独安装。安装操作和创作教程分别见[图形安装说明](../user/graphical-installation.md)和[快速开始](../user/getting-started.md)。

## 验证范围

发布流程要求签名标签、最新主线、Java/Javadoc 与 UI 合约检查、构建溯源及发布资产核验。版本对应的来源与实际结果见[0.1.5 发布记录](../testing/maintenance-release-0.1.5.md)。

本轮已有 Windows Fabric 1.21.1 开发客户端的发光、透光、剪羊毛、刷怪蛋、普通船和同一世界存档重开证据；另外三种船变体通过生成和编译验证。完整安装器的既有 Windows／Ubuntu VM 记录绑定其原始源码与产物，不冒充最终 0.1.5 包的完整复测。26.3 候选及历史生成器门禁保持各自记录的验证范围。

已知问题：资产预览失败后切换语言，已有错误提示可能保留原语言；重试预览或重新打开资产可刷新提示。
