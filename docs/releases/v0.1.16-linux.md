# Copperbench 0.1.16 — Linux x86_64

本版本包含[Windows 0.1.16 说明](v0.1.16.md)中的简洁首作引导、运行时双语、模型目录与手动输入、思考强度、附件、会话权限、历史管理和停止/草稿恢复修复，以及隐藏侧栏的性能优化。

目标平台为 Ubuntu 24.04 LTS x86_64，提供图形安装 Setup.tar.gz、Debian .deb、便携 .tar.gz 和应用内更新组件。使用同一 Release 的 `linux-candidate-sha256.txt` 核对下载；安装步骤见[中文](../user/linux-installation.md)或[English](../user/linux-installation.en.md)。

Linux 按独立维护版本流程晋级经过验证的固定候选文件：检查平台/生成器回归、图形安装器渲染、包内容及文件模式、随包无系统 Java/Gradle/Git 启动、JCEF 与 Fabric/NeoForge X11 渲染、独立消费者核验、签名来源证明及草稿下载字节一致性。确切候选、来源提交和发布结果见[0.1.16 发布记录](../testing/maintenance-release-0.1.16.md)及发布载荷中的 `LINUX-RELEASE-AUTHORIZATION.json`。

这些检查不构成新的完整 GNOME/Wayland 安装、升级、卸载或玩家操作认证，`formalSupportClaim=false`。本轮 Windows + Codex 的完整首作不外推为 Linux 或其他 CLI 的完整首作。历史平台证据保留原范围；各平台已公开版本以[当前下载](current.md)为准。
