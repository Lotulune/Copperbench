# Copperbench 0.1.13 — Windows

0.1.13 减少应用内更新时不必要的文件修改，并完善更新助手的身份说明。

- 更新保留现有桌面和开始菜单快捷方式，包括自定义参数、名称及用户主动删除的选择。
- 更新登记失败时，不再重写内容未变化的关联文件。
- 更新助手的程序说明明确其更新与卸载职责；安装前显示中英文助手名称、文件替换及管理员权限说明。
- 同步帮助页、版本清单和界面握手版本为 0.1.13。

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包仍未进行 Authenticode 签名，SmartScreen 可能显示提示。

本版减少快捷方式写入，没有确认 360 告警已消失。代码检查、快捷方式保留测试及中英文弹窗显示的验证记录见[更新助手修复](https://github.com/Lotulune/Copperbench/blob/main/docs/testing/update-helper-2026-10-19.md)。最终包的 360 复扫和完整实机安装、升级、卸载未在本次发布前重复；不影响历史证据的原有范围。

源码由签名标签 `v0.1.13` 标识，具体提交与云端构建记录见随包的 `RELEASE-METADATA.json`。生成器支持矩阵沿用随包 `product-status.json`，本次不扩大支持范围。Linux 公开版本仍为 0.1.9。
