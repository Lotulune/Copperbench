# Copperbench 0.1.16 — Windows

0.1.16 完善简洁创作的首次使用、助手选项和失败恢复。

- 五种 CLI 的检测与安装帮助、简洁和专业模式的分步遮罩教程，以及中英文首作路线。
- 从助手实际协议或上游获取模型目录，支持搜索、刷新及手动模型 ID；模型右侧提供五档思考强度并说明兼容范围。
- 支持文件与图片附件、预览及会话权限选择；保留各 CLI 的审批流程，准确提示不支持的图片输入。
- 产品审批、停止、连接和历史提示支持中英文；聊天支持 Markdown 和复制，历史支持导出、删除、容量提示及恢复。
- 修复快速停止误重发、停止后的草稿归属、删除对话遗留草稿和保存/附件清理错误反馈。
- 顶部模式切换增加平滑展开与收拢，交付按钮对齐；专业模式不再反复创建隐藏的简洁模式作品列表。README 增加项目状态徽章。

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。各助手使用本机既有 CLI 配置与登录；模型强度和图片能力取决于实际 CLI、模型及上游服务。

签名标签 `v0.1.16` 标识发布源码；准确提交、文件摘要及构建来源见 `RELEASE-METADATA.json` 和 GitHub provenance。生成器及开发预览范围沿用随包 `product-status.json`。

本地 Windows + Codex 候选已完成真实首作、附件、审批、停止、Minecraft 方块放置/保存重开、普通导出及应用重启后继续；[验收记录](../testing/simple-mode-final-package-2026-10-22.md)绑定当时的具体候选哈希。正式重建包的检查与该记录分开报告，见[发布记录](https://github.com/Lotulune/Copperbench/blob/07924ba11a00a8bab9ac1b720bbc01867f27a506/docs/testing/maintenance-release-0.1.16.md)。未重复完整安装/升级/卸载、360 复扫、朋友新手研究或五 CLI 全平台首作。

Linux 使用独立的 [0.1.16 发布说明](v0.1.16-linux.md)，公开包以[当前下载](current.md)为准。
