Model import now keeps the modeling-task panel available during asset refresh, so import → bind → refresh can continue without reopening the panel. Clipboard feedback reports success only after copying succeeds and explains failures. Current setup and capability documentation has been aligned with the implemented platform and element catalog.

Asset reads, references, diagnostics and health calculations share an internal service. Public MCP/SDK contracts, workspace storage, revision protection and recovery behavior are unchanged.

This Windows 11 x64 release includes the installer, portable ZIP and MSIX, plus checksums, release metadata, SPDX SBOM and license notices. Windows binaries are not Authenticode signed. Verify `SHA256SUMS.txt` and GitHub provenance before installation. First builds need network access; offline use depends on a verified dependency cache. Blockbench remains a separate installation.

Source validation includes Java/Javadoc, UI-Core and MCP checks, a full Chromium regression and a real native JCEF model import/bind/refresh replay. The new Linux package also completed all ten installed gates and both preference-migration checks before publication.
