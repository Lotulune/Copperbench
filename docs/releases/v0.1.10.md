# Copperbench 0.1.10 — Windows

0.1.10 更新了桌面界面、产品图标和应用内升级体验。

- 启动画面跟随系统语言或已保存的语言选择；首页重新安排工作区入口、最近项目和辅助工具。
- 手动检查更新集中在「帮助与关于」。后台发现新版本后，左下角显示浅蓝色更新按钮和目标版本。
- 支持按组件下载更新，复用未变化的运行环境；校验完成后等待应用正常退出，在原目录升级并重新启动，保留用户文件和偏好。
- 改善弹窗的主题、中英文文案、换行和布局；工具展开、菜单和页面切换加入过渡，并遵循减少动态效果设置。
- Windows 窗口最外沿使用系统圆角，保留最大化与贴靠行为。
- 统一使用铜工作台图标，覆盖应用、启动页、安装器、卸载器及安装包资源，并检查最终安装 EXE 内的实际图标。

Windows x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。下载后可用同一 Release 的 `SHA256SUMS.txt` 校验文件。Windows 包继续采用 Authenticode 未签名分发。

验证范围及候选包记录见 [0.1.10 发布记录](https://github.com/Lotulune/Copperbench/blob/v0.1.10/docs/testing/maintenance-release-0.1.10.md)。本次 Windows 发布不改变 Linux 0.1.9 的公开版本和既有验收范围。
