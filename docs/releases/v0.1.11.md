# Copperbench 0.1.11 — Windows

0.1.11 补齐原生提示窗的界面优化。

- 独立升级窗口使用产品图标和应用主题，启动升级时重新读取当前语言与主题。
- 等待程序退出、准备安装、复制文件和授权等待分别显示对应状态；等待阶段不再出现误导性的 `0%`，安装开始后不再继续提示关闭程序。
- 通用确认、错误、输入和详情窗口使用统一控件样式。长文本可换行、滚动，保留输入框和键盘操作。
- 安装器的主题、语言下拉框和子窗口统一外观；小窗口下表单纵向滚动，主要操作始终可见，浏览与许可按钮不再被横向裁掉。
- 主程序进度框统一颜色与留白，长文件路径完整换行；默认按钮、复选框和进度数字在明暗主题下保持可辨识。

Windows x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包继续采用 Authenticode 未签名分发。

验证范围见 [原生窗口验证记录](https://github.com/Lotulune/Copperbench/blob/main/docs/testing/native-dialogs-2026-10-19.md)。本次 Windows 发布不改变 Linux 0.1.9 的公开版本和既有验收范围。
