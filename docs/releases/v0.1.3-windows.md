Add a **JAR folder** button beside **Build** in the top toolbar. It opens the current workspace's `build/libs` folder in the system file manager. If the folder does not exist yet, Copperbench asks you to build the workspace first.

This is a small Windows 11 x64 maintenance release. The installer, portable ZIP and MSIX include the same change. Windows packages remain unsigned by Authenticode; SmartScreen may show a warning. Checksums, source metadata and GitHub build provenance accompany the downloads.

Validation: UI production build and localization checks, Java compilation and three related tests, 22 existing titlebar/layout regression cases, and a browser replay of the native-host call, missing-folder guidance and unavailable-host state. The browser replay uses a stub host; opening Explorer from the installed client was not re-tested. Existing generator and platform support claims are unchanged; no new gameplay or Linux installed acceptance is claimed.

Linux remains available as [0.1.2](https://github.com/Lotulune/Copperbench/releases/tag/v0.1.2-linux-stable). Source changes for the button are included in 0.1.3, but this release does not provide new Linux packages.
