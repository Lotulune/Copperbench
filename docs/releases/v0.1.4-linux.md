# Copperbench 0.1.4 — Linux x86_64

本次更新包含新版 Product Shell、源码编辑、关系图、资产预览和设置，与 Windows 0.1.4 使用相同的产品源码。

- 简化导航与页面文字，调整列表、表单和紧凑窗口的间距及对齐。
- 浏览、搜索和编辑手写源码；切换页面保留草稿，保存时检查外部修改。生成器管理的文件保持只读。
- 关系图展示 Mod Element、资产和未解析引用，支持搜索、展开、平移、缩放和拖动节点；节点位置不会改变工作区数据。
- 资产页支持分类筛选、图片和模型预览；设置提供主题、语言与源码编辑器偏好。
- 改进 MCP 权限持久化、SDK 响应校验和任务事件处理；CI 按改动范围选择检查。

## 安装

提供 Debian `.deb` 和便携 `.tar.gz`，内置 JBR 25/JCEF 与 Java 21。

```sh
sudo apt install ./copperbench_0.1.4_amd64.deb
```

便携版解压后运行 `copperbench.sh`。使用同一 Release 中的 `linux-candidate-sha256.txt` 校验下载；GitHub 会将便携包文件名中的空格改为点号，文件内容和哈希不变。首次构建需要联网，Blockbench 需单独安装。
