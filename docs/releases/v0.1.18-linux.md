# Copperbench 0.1.18 — Linux x86_64

本版本包含 [Windows 0.1.18 说明](v0.1.18.md)中的静态模型与元素预览、专业工作台 Agent、Blockbench 响应与保存同步修复。

**English:** Linux ships the same static previews, professional Agent workflow and Blockbench fixes. Release assets are promoted from an independently verified frozen main candidate without rebuilding.

目标平台为 Ubuntu 24.04 LTS x86_64，提供图形安装 Setup.tar.gz、Debian .deb、便携 .tar.gz 和应用内更新组件。使用同一 Release 的 `linux-candidate-sha256.txt` 核对下载；安装步骤见[中文](../user/linux-installation.md)或 [English](../user/linux-installation.en.md)。

固定候选发布流程验证平台与生成器回归、包内容和文件权限、随包启动、安装器渲染、JCEF 与 Fabric/NeoForge X11 渲染、独立消费者核验、来源证明及完整草稿下载比对。具体结果见[本轮发布记录](../testing/maintenance-release-0.1.18.md)和随包 `LINUX-RELEASE-AUTHORIZATION.json`。

本轮不扩大完整 GNOME/Wayland 安装、升级、卸载、真实 CLI 账号或玩家操作认证，`formalSupportClaim=false`。静态预览范围与 Windows 相同；Windows 原生验证不转用于 Linux 安装认证。各平台公开状态以[当前下载](current.md)为准。
