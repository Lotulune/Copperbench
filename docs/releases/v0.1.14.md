# Copperbench 0.1.14 — Windows

该签名源码的 Windows 发布流程在原生诊断测试阶段失败，没有公开安装包。失败记录见[发布准备记录](../testing/maintenance-release-0.1.14.md)；修复后的两平台版本使用 [0.1.15](v0.1.15.md)，下载以[当前下载](current.md)为准。

0.1.14 新增适合普通玩家的简洁创作界面，可随时切换到专业工作台。

- 通过对话创作模组，接入主机安装的 Codex CLI、Claude Code、Grok Build、Antigravity CLI 和 DeepSeek Harness；每种助手都有图标，支持授权、澄清问题、停止和历史续聊。
- 简化新建作品，提供原生文件与目录选择器，复用现有恢复点、试玩和导出流程。切换模式保留草稿、工作区和任务。
- 修复未发送聊天、未保存参数和专业编辑内容的保护，以及重复新建作品的表单状态。
- 改善任务入口、流式日志跟随、即时语言切换、叠加弹窗焦点和 MCP 重新配对体验。
- 修复原生配置窗口的按钮对比度、进度百分比裁切和标题栏按钮点击区域。

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。创作助手使用本机各自的 CLI 配置和登录状态；Claude Code 直接调用已安装的官方程序。

源码由签名标签 `v0.1.14` 标识，构建提交与工作流记录见 `RELEASE-METADATA.json`。生成器支持矩阵和开发预览范围沿用随包 `product-status.json`。本轮源码验证见[简洁模式集成记录](https://github.com/Lotulune/Copperbench/blob/main/docs/testing/simple-creation-merge-2026-10-21.md)；最终包的完整安装、升级、卸载、360 复扫和玩家操作验收未重新执行，不扩展历史证据的范围。

Linux 使用独立的 [0.1.14 发布说明](v0.1.14-linux.md)；各平台的公开下载以[当前下载](current.md)为准。
