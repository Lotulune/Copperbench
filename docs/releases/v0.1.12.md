# Copperbench 0.1.12 — Windows

0.1.12 收紧应用内更新窗口的布局。

- 移除状态区固定预留的五行空白，窗口高度随实际文字调整。
- 缩小外边距及标题、状态、进度条和按钮之间的间隔；短提示不再撑高窗口。
- 长提示继续自动换行并保留滚动空间，中英文及高缩放下的操作按钮完整可见。

Windows x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用本 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包继续采用 Authenticode 未签名分发。

验证范围见[紧凑更新窗口记录](https://github.com/Lotulune/Copperbench/blob/main/docs/testing/compact-update-dialog-2026-10-19.md)。Linux 公开版本仍为 0.1.9。
