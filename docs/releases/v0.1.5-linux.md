# Copperbench 0.1.5 — Linux x86_64

Linux 0.1.5 包含[Windows 0.1.5 的同一批产品改进](v0.1.5.md)：输入诊断、首作教程、草稿与数字输入修复、创建默认值、光照字段和 Fabric 1.21.1 模板修复，以及双语离线安装器和 Blockbench 工作流。

## 安装

提供 Debian `.deb`、便携 `.tar.gz` 和独立图形安装向导 `Setup.tar.gz`，内置 JBR 25/JCEF 与 Java 21。图形安装包解压后运行 `Install Copperbench`；便携版运行 `copperbench.sh`。

```sh
sudo apt install ./copperbench_0.1.5_amd64.deb
```

安装器替换收据时保留原有 POSIX 权限，修复系统安装后普通用户无法读取卸载记录的问题。详细操作见[图形安装说明](../user/graphical-installation.md)和[Linux 安装说明](../user/linux-installation.md)。首次构建需要联网，Blockbench 单独安装。

使用同一 Release 的 `linux-candidate-sha256.txt` 校验下载。GitHub 会将包名中的空格改为点号，文件内容与哈希不变。

## 来源与验证范围

Linux 发布使用冻结候选包；`LINUX-CANDIDATE-METADATA.json` 标识原始产品源码、候选运行和包摘要，`LINUX-RELEASE-AUTHORIZATION.json` 记录该候选的实际验收与发布范围。发布前必须核对来源证明、逐个资产的哈希及下载后的草稿字节。

平台范围为 Ubuntu 24.04 LTS x86_64。候选 CI 的包结构、隔离启动、JCEF X11 和 Fabric／NeoForge 渲染预检，与完整 GNOME Wayland/Xorg 安装验收分别记录；不将 CI 或旧版本 VM 结果替代新包的完整安装验收。实际状态见[0.1.5 发布记录](../testing/maintenance-release-0.1.5.md)。其他发行版与架构未验证。
