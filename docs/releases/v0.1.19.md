# Copperbench 0.1.19 — Windows

0.1.19 换上全新的 Notebook 界面，并修复专业工作台 Agent 审批与后端一致性问题。

- 界面改为白色纸页、冷灰桌面和笔蓝强调色，覆盖简洁创作、专业工作台、对话框与各专业编辑器；按钮按压、视图进入、主题切换和菜单展开都有简短动效，并在系统减少动态效果时关闭位移动画。
- 每种元素类型使用统一的类型图标与色块，出现在列表、卡片、标签页、创建对话框、检查器和编辑器标题中；移除重复标题、面包屑和健康状态等冗余文字，完整说明仍提供给辅助技术。
- 专业工作台 Agent 的待批准请求固定显示在运行设置上方，不再随标签页切换隐藏；折叠的 Agent 按钮会提示“等待你的处理”。不支持交互审批的 CLI 拒绝操作时，两个工作台给出相同的配置提示。
- 资产导入与工作区修改保持事务一致，工作区事件按顺序送达界面，任务取消和命名工作区迁移更可靠。

**English:** This release introduces the Notebook interface across simple creation, the professional workbench, dialogs and specialist editors; keeps professional Agent approvals visible above the run settings; shares CLI permission guidance between both workbenches; and includes backend fixes for asset-import transactions, ordered workspace events, task cancellation and named workspace migration.

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用同一 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。签名源码标签为 `v0.1.19`；准确提交、文件摘要和构建来源见 `RELEASE-METADATA.json` 及 GitHub provenance。

界面改版不改变工作区格式、生成器支持或 Minecraft 游戏代码。Blockbench 与创作 CLI 仍需单独安装和配置。源码回归、界面验证及正式包记录见[本轮发布记录](../testing/maintenance-release-0.1.19.md)。生成器支持与开发预览范围沿用随包 `product-status.json`。

Linux 使用独立的 [0.1.19 发布说明](v0.1.19-linux.md)，公开下载以[当前下载](current.md)为准。
