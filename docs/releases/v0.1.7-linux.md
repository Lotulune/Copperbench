# Copperbench 0.1.7 — Linux x86_64

本版包含与 [Windows 0.1.7](v0.1.7.md)相同的数据包 ZIP 默认路径和自定义 Gradle 归档目录导出修复。

目标环境为 Ubuntu 24.04 LTS x86_64，提供 Debian `.deb`、便携 `.tar.gz` 与图形安装包 `Setup.tar.gz`。安装方法见[Linux 安装说明](../user/linux-installation.md)。校验使用本 Release 的 `linux-candidate-sha256.txt`。

Linux 通过既有冻结候选流程核对源码、资产摘要及来源证明后发布。候选 CI 的包结构、启动和渲染检查与完整 GNOME 安装或 Minecraft 玩家操作验收分别记录；本次未重新执行后两项。实际来源与发布结果见[0.1.7 发布记录](../testing/maintenance-release-0.1.7.md)。
