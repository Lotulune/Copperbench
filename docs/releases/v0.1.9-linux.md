# Copperbench 0.1.9 — Linux x86_64

0.1.9 包含 Gradle 配置缓存导出、1.20.1 数据包旧 wrapper 迁移，以及归档物理路径校验的修复。自定义分发地址、项目设置和 JAR 摘要检查保留。

Ubuntu 24.04 LTS x86_64 提供 Setup.tar.gz、DEB 和便携 tar.gz，使用本 Release 的 `linux-candidate-sha256.txt` 校验下载。冻结候选及来源证明与正式桌面、玩家验收范围分别记录。

0.1.8 候选没有晋级发布。修复与验证记录见[0.1.9 发布记录](../testing/maintenance-release-0.1.9.md)。
