# Copperbench 0.1.8 — Windows

0.1.8 修复 NeoForge 等启用 Gradle 配置缓存的项目无法普通导出模组的问题。导出现在只对本次归档回执任务关闭配置缓存，保留项目设置、构建缓存和 JAR 摘要校验；自定义归档目录继续受支持。

Windows 11 x64 提供 EXE、便携 ZIP 和 MSIX。使用本 Release 的 `SHA256SUMS.txt` 校验下载；Windows 包保持 Authenticode 未签名分发。

问题来自公开 0.1.7 包的云端验收。修复与验证进度见[0.1.8 发布记录](../testing/maintenance-release-0.1.8.md)。
