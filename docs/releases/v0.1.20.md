# Copperbench 0.1.20 — Windows

0.1.20 打磨 Notebook 界面的新建工作区、设置与对话框，并修复简洁创作中嵌入视图的按钮样式。

- 新建工作区每个 Minecraft 版本占一行，加载器作为选项，整份目录一屏可见；确认框和创建按钮固定在底部栏，显示保存路径，并在禁用的按钮旁说明第一项未满足的条件。创建成功后回到顶部显示结果。
- 设置中的开关类选项改为开关，各行排在同一张纸页上；搜索框和整数字段恢复应有尺寸。确认对话框更窄，打开工作区对话框把路径和浏览按钮放在同一行。
- 简洁创作中打开的资产、恢复点、设置和新建视图恢复主按钮和选中状态；导览改为图标按钮，会话管理入口仅在有会话或存储需要处理时出现。
- Agent 输入框的推理强度与权限菜单在上方放不下时改为向下展开。版本与迁移中的输入框恢复背景色。

**English:** This release refines the Notebook new-workspace view (one row per game version, a confirmation bar that names the first unmet requirement), turns on/off settings into switches, narrows confirmation dialogs, restores primary buttons and selected states in views opened from simple creation, and lets composer option menus open below when there is no room above.

Windows 11 x64 提供图形安装 EXE、便携 ZIP、MSIX 和应用内更新组件。使用同一 Release 的 `SHA256SUMS.txt` 校验下载。Windows 包未进行 Authenticode 签名，SmartScreen 可能显示提示。签名源码标签为 `v0.1.20`；准确提交、文件摘要和构建来源见 `RELEASE-METADATA.json` 及 GitHub provenance。

本版本不改变工作区格式或 Minecraft 游戏代码。26.2 生成器中与 26.1.2 相同的模板改为从基线继承，源码检查确认解析结果一致；仓库同时删除了重复的生成器源码副本和不再使用的脚本，不影响安装包功能。Blockbench 与创作 CLI 仍需单独安装和配置。验证范围见[本轮发布记录](../testing/maintenance-release-0.1.20.md)。

Linux 使用独立的 [0.1.20 发布说明](v0.1.20-linux.md)，公开下载以[当前下载](current.md)为准。
