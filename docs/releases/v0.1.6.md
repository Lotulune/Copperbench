# Copperbench 0.1.6 — Windows

0.1.6 整合首作、编辑恢复、构建交付与 SDK 改进。[Windows 稳定版](https://github.com/Lotulune/Copperbench/releases/tag/v0.1.6)于 `2026-10-15T15:35:41Z` 公开，提供 EXE、便携 ZIP 和 MSIX。来源与实际结果见[发布记录](../testing/maintenance-release-0.1.6.md)。

## 首作与交付

- 启动窗口增加「第一件作品 · 步道方块」和外部 Agent 接入帮助；首作预设复用现有工作区创建、目录校验和确认流程。
- 工作区引导记录当前作品、构建、客户端与交付任务，提供观察和正常退出后重开同一世界的步骤。
- 普通模组导出使用本次 Gradle 归档任务声明的产物并核对摘要，保护已有文件和源码、依赖、元数据及运行目录；精确导出继续绑定所选验收任务与产物身份。

## 编辑恢复与诊断

- 保留跨页面和外部修改后的草稿、非法数字中间输入及未知保存状态；只读或被移除字段的草稿仍可审阅和明确丢弃。
- 迟到读取保留已关闭的首作引导偏好和原任务引用，重读期间发生 revision 变化时保留草稿。
- 编译诊断按真实生成路径和持久化元素 ID 定位，使用各条诊断的源码行号；已加载文件的重复跳转也重新选择并聚焦。

## Agent 与开发工具

- SDK 支持原 taskId 与日志序号恢复、选字段分页和显式复用新读到的环境；保留主线字段发现、doctor、生成预检、26.3 预览和版本复制合同。
- 修复 Native 独立宿主空闲关闭、附加连接 socket 释放及 CRLF／UTF-8 响应字节计量。
- 新增中英文首作、构建导出和 Agent 路线，提供按变更选择检查的贡献者入口。
- 性能记录绑定源码与测量阶段，分别比较反馈、输入到就绪和总阶段；现有数据只构成其原环境的基线，不宣称整体提速。

0.1.5 的双语离线安装器、输入诊断、创建默认值、光照及 Fabric 模板修复保留。26.3 仍按显式预览能力与协商范围使用。

## 安装与验证范围

提供 Windows 11 x64 的 EXE、便携 ZIP 和 MSIX。发布流程要求最新主线的签名标签 `v0.1.6`、Java／Javadoc 与 UI 合约检查、SBOM、来源证明及发布资产核验。Windows 包保持现有 Authenticode 未签名分发方式。

二进制源码为 `9e3dfdeab1bc19c099e739bcda14940d9a6fee30`。[主线 CI](https://github.com/Lotulune/Copperbench/actions/runs/38748273169)与[发布运行 attempt 2](https://github.com/Lotulune/Copperbench/actions/runs/38748647623/attempts/2)成功；九项校验清单条目与公开 API 摘要一致，SHA256SUMS 自身及另两个元数据文件另做字节核对，十项签名来源证明均通过。公开 ZIP 整包摘要和内部 23 项文档／SDK／schema 字节与 A 一致。初次 Sigstore 网络失败及历史优化候选的失败／复验保留原记录。最终包未新增完整安装或 Minecraft 玩家／存档验收结论。
