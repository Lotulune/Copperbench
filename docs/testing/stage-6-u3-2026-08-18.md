# Stage 6 U3 资产基础链路证据（2026-08-18）

## 已完成

- Java `dev.copperbench.assets` 提供确定性扫描、稳定路径身份 ID、SHA-256 内容指纹、分类、搜索、授权路径解析和 JSON/Minecraft 资源引用图。
- UI-Core 新增 `urn:ui-core:1.0:asset` 投影 schema 与引用图 fixture。
- UI-Shell `AssetBrowserView` 接入资产导航，覆盖稳定 ID、分类/搜索/排序、预览详情、引用关系、ready/empty/loading/error 状态和 Blockbench 打开事件。
- MCP 在保持原有启动 API 的前提下增加可选 `list_assets` 与 `inspect_asset_references` 工具；两者使用同一审计日志和工作区路径限制。
- JCEF 新增 `copperbench:blockbench:` 窄路由；仅暴露 `status` 与 `openAsset(assetId)`，并由 Java 管理进程生命周期和路径授权。
- Blockbench 退出后重新比较打开时与当前内容 SHA-256；外部修改会返回 `ASSET_CHANGED_EXTERNALLY`，阻止静默回写。
