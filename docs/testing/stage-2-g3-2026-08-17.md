## 官方 MCP conformance

- 版本：`@modelcontextprotocol/conformance 0.1.16`，协议 `2025-11-25`。
- 适用场景：初始化、日志级别、ping、工具目录、多 POST/SSE 流、DNS rebinding 防护，共 8/8 检查通过。
- 认证方式：官方 CLI 不支持自定义请求头，因此通过测试专用回环代理注入生产服务器要求的短期 Bearer token 与 workspace header；Host/Origin 原样转发，DNS 防护仍由生产守卫验证。
- 全量 active suite 探索结果保留为 8 通过、24 失败；失败项是未声明的 conformance 专用 completion、富内容工具、resource、prompt、sampling、elicitation 能力，未作为产品适用门禁。
- Windows 上 CLI 在成功写出单场景报告后可能触发 `UV_HANDLE_CLOSING` 断言；验证脚本以官方生成的 `checks.json` 为准。
- 汇总见 [`mcp-conformance-summary.json`](../../evidence/stage-2/2026-08-17/mcp-conformance-summary.json)，复现脚本为 [`verify-mcp-conformance.ps1`](../../scripts/verify-mcp-conformance.ps1)。
