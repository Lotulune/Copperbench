# 安装器字形、实体创建与首作分流修复

日期：2026-10-15（Asia/Tokyo）。基线为 `bc2a512ca07b8c38fe1ff3140b3954563925bc6a`，工作分支为 `codex/installer-creator-repair`。本轮是 0.1.5 发布后的源码修复，没有替换公开的 0.1.5 包或发布新版本。

## 修复范围

- 安装器直接加载随包 Noto Sans CJK SC 2.004，覆盖普通／粗体绘制文字、复选框、选择框、许可及文件选择器默认字体。字体源、固定摘要和 OFL 许可随安装器一起提供；不安装系统字体。许可对话框增加字体许可页。
- 预览检查真实控件文字的 `Font.canDisplayUpTo`；缺字抛错并输出字体和 Unicode 码点，开始检查前清除旧的成功回执。每种缩放生成中英、深浅、准备／进度／完成／错误及三个许可页共 28 张图。JSON 绑定安装器 JAR、源码清单、字体和每张图的 SHA-256；图片仍需要视觉检查截断与对比度。
- Linux 候选 CI 使用最终包解出的 JDK/JAR 做预览，增加字体回归、回执与图像哈希校验、主机中文字体清单和失败证据上传。该配置已修改，本轮没有启动远端 CI。
- 新建生物／特殊实体查询 Core 创建要求并选择已导入的实体贴图；不移除底层必填校验。生物传入带 `.png` 的文件名，特殊实体传入资源名。缺失／失效贴图保留草稿，可前往资产页导入后返回继续。未增加自动纹理生成或新的默认实体贴图。
- `lightValue` 继续拒绝，但提供 `luminance`／`lightOpacity` 的修复提示。原生误用 MCP `read_mod_element` 时明确提示 `get_mod_element_editor`，不增加协议别名。
- GUI 首作移出 JSON/revision 协议说明，增加独立 Agent 首作及英文安装／首作指南，修正 SDK 接口映射说明，并把新增指南加入导出配置。
- GitHub About 已通过 API 修改并读回确认：Windows 11／Ubuntu 24.04、Fabric／NeoForge、Blockly、local MCP 和 SDK automation；保留独立 MCreator 衍生项目及 GPL-3.0-only 身份。

## 保留的边界与实包验收

用户提供的 Linux CI 缺字截图证明旧门禁会漏报；旧 Ubuntu VM 的中文可读截图说明故障并非所有 Linux 环境必现。当前修复消除了向导对系统中文字体的依赖，但本轮没有在 Linux 桌面上重现／关闭原故障，不能据此宣布原始 0.1.5 包已通过。

当前没有注册的 Hyper-V 测试客体，WSL 未安装；没有重建测试系统或替换宿主现有安装。因此最终 0.1.5 的完整安装→首启→首作→构建→客户端→保存重进→正常退出，以及升级／卸载数据保留，仍为 **未验证**。文件引擎测试不是系统安装验收，浏览器创建测试也不是 Minecraft 验收。

后续实包只需定向短流程：Windows 11 和 Ubuntu 24.04 GNOME 各以独立工作区及唯一世界跑 Fabric 1.21.1 首作；Ubuntu 补另一显示会话的启动和中文可读性检查。分别检查旧 0.1.4 升级、当前用户安装与 Linux 系统 `.deb` 路径，核对设置、工作区、资产和存档保留。退出确认进程、游戏日志和 Copperbench 生命周期任务终态；证据放在 `output/minecraft-validation` 并绑定实际源码／包摘要。无需无差别重跑全部历史矩阵。

`formalSupportClaim=false` 与 `fullInstalledAcceptance=not-repeated` 保留其候选验收含义；历史平台支持记录不被改写。`copperbench.stage15LinuxCandidate` 仍用于现有 Linux 启动准入，未直接移除或借此扩大支持宣称。

## 后续：统一选项控件

安装器和工作台现在使用一致的铜色选中标记、圆角边框、箭头、焦点与禁用状态。前端 21 个组件中的 40 处下拉菜单复用 `Select`，保留原生字段、label、表单提交和 change 事件；弹出菜单支持方向键、首尾跳转、输入检索、长列表滚动和窗口边缘避让。复选框与单选框采用共享样式。安装器保留原生 Swing 控件与内置中文字体，同时统一勾选、菜单、按钮和输入框。

实际桌面验证发现，展开菜单时按方向键切换主题会在替换内容面板时留下 popup，并触发 `IndexOutOfBoundsException`。已在延迟刷新前显式关闭菜单，更新独立交互回归并接入 Linux candidate CI。前端弹窗则让已展开的下拉菜单先处理 Escape，下一次 Escape 才关闭表单。

- 前端 36 项单测与生产构建通过。浏览器在 1920×1080 和 1366×768 下覆盖 66 个不同用例；初轮 56 项通过，8 项新增测试因英文文案预期或重新加载后折叠区域未展开而失败，修正测试后 8 项通过；修复 Escape 后，受影响的 38 项（含 2 项新用例）再次全部通过。
- 安装器独立编译、保持 popup 展开的语言／主题切换回归通过；100%／150%／200% 各 28 张预览的字形与摘要门禁通过。人工查看深浅主题、中文／英文菜单、禁用状态、紧凑表单和高缩放图像，未观察到缺字或控件文字裁切。
- 使用 computer-use 在 Windows 11 上实际点击菜单、用 Down 切换浅色、点击与 Space 切换许可勾选、选择 English，再点击 Cancel 正常退出；修复后进程退出码为 0，日志无异常。没有执行安装动作。
- 证据保存在 `output/control-polish/`，其中 `summary.json` 绑定源码、最终向导 JAR、前端构建和截图摘要；`desktop/` 是实际 Windows 窗口截图，`installer-*` 是 Swing 渲染，`browser*` 是 Chromium 验证。
