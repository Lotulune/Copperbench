## Publication procedure and current state

The first Windows release attempt, [run 38558013749](https://github.com/Lotulune/Copperbench/actions/runs/38558013749), stopped at release tests before packaging or publication. Eight version-copy cases exposed a Windows short-path mismatch between preview choice and the canonical destination; the ninth failure was a native accessibility test assuming Chinese labels on an English interface. Preview choices now use the existing link-rejecting workspace path canonicalizer. The accessibility test checks the complete labels for the actual UI language. Both regressions are included in Windows pull-request CI. The failed tag object `bd705ba789b8e313968039861ff0e6108786c6b9` identified source `cb616b878da983864f7747cfa7b0ae09513ffef7`; its failed run remains available. No public 0.1.5 assets existed at that point.

The merged source's Windows [CI run 38564546126](https://github.com/Lotulune/Copperbench/actions/runs/38564546126) then exposed an asynchronous readiness gap in that accessibility test: the outline tab can mount before `getProcedureEditor` supplies its nodes. The second [release attempt 38564677751](https://github.com/Lotulune/Copperbench/actions/runs/38564677751) was cancelled during testing before packaging. The test now waits for the full localized node/port condition and reports the observed language, loading state and accessible labels on timeout; no product behavior or accessibility requirement is relaxed.

Windows and Linux 0.1.5 are public. [Current downloads](../releases/current.md) now point to the verified packages.

Windows was built and published by the protected workflow with a signed `v0.1.5` tag that matched latest main at the release checks, clean-source verification, packaging, SBOM, SHA-256 manifests, provenance and draft-asset checks. Linux promoted the unchanged frozen candidate under its separately signed tag. Candidate identity, exact hashes, completed CI and public verification receipts are recorded below.

The host currently has no registered Hyper-V VM and the earlier `D:/Hyper-V/UX-Joint-20261013` guest directory is absent. No fresh full clean-Linux installed acceptance is claimed. The prior 0.1.3/0.1.4 candidate-specific maintenance exceptions are not reused for 0.1.5.
