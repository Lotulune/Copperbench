# ADR-0002：同时支持 Fabric 与 NeoForge，并以 Fabric 为主

- 状态：已接受
- 日期：2026-08-16

## 决定

Fabric 是主加载器，NeoForge 是辅加载器；两者都属于正式产品支持范围。通用模组元素应在同一里程碑覆盖两个加载器，加载器专属能力允许 NeoForge 最多落后一个里程碑。

## 原因

Fabric 决定默认功能设计和优先验证顺序，但 NeoForge 不能退化为社区插件或“尽力而为”的兼容模式。明确时限可以防止“Fabric 优先”逐渐变成“只有 Fabric”。

## 后果

- 每个通用功能都需要 Fabric 与 NeoForge 的生成、构建和测试用例。
- 加载器专属功能必须在需求与 UI 中明确标识，不能伪装成跨加载器功能。
- 发布计划需要分别报告两个加载器的功能矩阵和已知差异。
