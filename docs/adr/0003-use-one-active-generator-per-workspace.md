# ADR-0003：每个工作区只使用一个活动生成器

- 状态：已接受
- 日期：2026-08-16

## 决定

一个工作区同一时刻只选择一个由“加载器 + Minecraft 版本”组成的活动生成器。首期不从同一工作区同时生成 Fabric 与 NeoForge 产物。

后续可以提供加载器迁移，但迁移必须是用户可见、可验证、可回滚的独立流程；不以隐藏的双向同步实现。迁移默认创建新的工作区副本并输出完整报告，不原地修改源工作区。

## 原因

Fabric 与 NeoForge 存在真实的功能、生命周期和 API 差异。强制统一生成会隐藏信息损失，并让加载器专属功能难以表达。

## 后果

- 工作区模型需要明确记录活动生成器。
- 迁移工具必须报告不支持项、替代项和人工处理项。
- 用户可以在验证迁移结果后自行归档或替换源工作区。
- 不承诺 Fabric 与 NeoForge 之间无损往返；每次迁移都重新评估信息损失。
