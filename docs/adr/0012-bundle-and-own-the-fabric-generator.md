# ADR-0012：内置并负责维护 Fabric 生成器

- 状态：已接受
- 日期：2026-08-16

Fabric 是主加载器，因此产品不能要求创作者另行安装社区生成器。项目将在保留作者署名、许可文本和修改记录的前提下，将 [MCreator Fabric Generator](https://github.com/Goldorion/Fabric-Generator-MCreator) 的选定版本作为第一方内置生成器维护，并为四条版本轨道建立自己的构建与回归责任。

目标分支仓库中的 `LICENSE` 与 README 声明 GPL-3.0，和本产品许可兼容；MCreator 插件页同时显示 LGPLv3，存在发布元数据不一致。首次导入必须固定具体提交、保存许可证据并检查文件级声明，不能从滚动分支无审查复制代码。

内置不表示抹去项目来源，也不表示原作者为本产品背书。后续应尽量向原项目贡献可独立采用的修复，但产品发布不能依赖其维护节奏。
