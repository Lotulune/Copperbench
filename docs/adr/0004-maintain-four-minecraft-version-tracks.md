# ADR-0004：维护四条 Minecraft 版本轨道

- 状态：已接受
- 日期：2026-08-16

## 决定

产品维护以下 Minecraft Java 版本轨道：

1. 最新稳定版。
2. 前一个稳定版。
3. Minecraft 1.21.1。
4. Minecraft 1.20.1。

每条轨道都必须覆盖 Fabric 与 NeoForge，但可按 ADR-0002 的优先级推进。

动态的最新稳定版和前一个稳定版获得完整新功能。Fabric 可以先进入稳定状态，NeoForge 最多晚一个里程碑并在 UI 中明确标记状态。固定的 1.21.1 和 1.20.1 轨道默认只承诺构建兼容、严重错误修复，以及经过单独评估的功能回移。

## 原因

动态新版本轨道满足新项目需求，1.21.1 与 1.20.1 固定轨道覆盖当前常见的长期模组生态。明确轨道可以把“支持”落实为可构建、可测试的发布责任。

## 后果

- 生成器、依赖、映射和测试矩阵的维护成本会随轨道数增长。
- 每个加载器独立标记预览、稳定或维护状态，不能用一个总状态隐藏差异。
- 若动态轨道与固定轨道重合，不重复建立生成器，但仍保留对应的支持承诺。
