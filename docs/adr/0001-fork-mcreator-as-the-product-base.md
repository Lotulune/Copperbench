# ADR-0001：以 MCreator 分支作为产品基础

- 状态：已接受
- 日期：2026-08-16

## 决定

产品采用独立品牌的 MCreator 分支，公开源代码并遵守上游 GPL-3.0 许可义务。产品不得使用会造成官方背书误解的 MCreator 商标、名称或视觉资产。

除产品外壳外，分支策略保持“浅分支”：新能力优先通过插件、稳定扩展点和隔离模块实现，只在扩展点无法满足正式产品要求时修改核心。用户界面重写是经过明确选择的例外，必须通过稳定领域服务与上游核心隔离。插件 API 与工作区格式以兼容上游生态为目标。

## 原因

MCreator 已具备成熟的可视化模组元素、生成器、资源管理、构建和游戏测试流程。从头实现这些能力会把主要投入消耗在基础设施，而不是 Fabric 优先、AI 操作、版本迭代和快速验证等产品差异上。

## 后果

- 需要持续吸收上游安全修复、Minecraft 版本更新和兼容性变化。
- 核心修改必须记录与上游的差异，避免长期形成不可合并的分叉。
- 上游 UI 变化不再能直接合并；产品需要维护自己的交互层和 UI 兼容适配。
- “兼容插件生态”表示维持 API/格式兼容并建立兼容测试，不等于承诺所有第三方插件永远可用。

## 依据
