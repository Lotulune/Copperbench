# ADR-0008：使用本地 Git 承载工作区历史

- 状态：已接受
- 日期：2026-08-16

首期版本管理面向单用户，以工作区内的本地 Git 历史承载可见版本、差异、恢复点和发布标记；连接 GitHub、GitLab 等远程仓库属于可选能力，不建设自有账户与云同步系统。MCreator 已依赖 JGit，沿用 Git 对象模型可以避免维护第二套历史格式，但 UI 必须使用“版本、恢复点、比较、还原”等产品语言，不能要求目标用户理解 Git 命令。

AI/MCP 创建恢复点时使用结构化元数据标记操作来源和关联任务。产品不得在未经确认时覆盖用户已有的远程配置、分支策略或提交历史。
