# 专业工作台 Agent

在专业工作台顶部点击 **Agent**，打开当前项目的侧边面板。也可以在任务日志中点击“让 Agent 分析”，或在源码编辑器中附带当前文件。内容会先进入输入区，由你检查、修改或移除，点击发送后才开始任务。

“对话”页签显示消息。批准请求和简洁版一样显示在输入区上方，查看“变化与验证”时仍可处理；收起面板时，Agent 按钮显示“等待你的处理”。底部“与 Agent 对话”输入框在查看“变化与验证”时也会保留；发送或按 `Ctrl+Enter`（macOS 为 `⌘+Enter`）后回到对话。任务运行时，同一位置显示停止按钮，可以先写好下一条消息，待当前任务结束后再发送。

专业版和简洁版共用当前工作区的 CLI 会话、批准请求和停止操作。收起面板、切换页面或切换模式不会停止任务。再次打开面板只读取状态，不会自动重新发送。关闭整个桌面工作区会停止其 CLI 进程并保存记录。

## 连接与权限

在输入框上方点击“模型、思考与权限”。Codex 的模型、可选思考档位及允许使用的权限配置从当前 CLI 读取；先选择模型，再选择其支持的思考强度。切换模型会清除原来的强度选择，并使用新模型公布的默认档位。留空的模型沿用当前会话设置，新会话使用 CLI 默认模型。

权限可选“工作区写入”“只读沙箱”“完全访问”，具体可选项受 CLI 管理策略限制。工作区写入和完全访问仍按需请求批准；只读沙箱拒绝扩大文件访问权限，外部工具使用各自权限。设置在下一次发送时生效并保存到当前会话，不修改 CLI 全局配置；运行中只允许查看设置。权限属于会话：在简洁创作中继续同一会话时沿用这里的选择。选择只读沙箱或完全访问后，设置栏直接显示当前权限，简洁创作的输入框上方也会提示，并可在空闲时恢复默认权限。本次旧工作区的高级选择器接通 Codex，其他工具沿用各自 CLI 配置。

使用本机已经安装的 CLI 和它原有的认证配置。连接区显示版本、可执行文件及权限配置；“检测到 CLI”只说明找到了可执行程序，认证和实际执行能力由真实任务验证。未安装时可以打开官方安装指引，其他项目功能不依赖 CLI。

当前复用简洁版已有的 Codex、Claude、Grok、Antigravity、DeepSeek 适配器。本次专业版首轮真实验证针对 Windows 本机的 Codex CLI 0.162.1 / app-server。其他平台和供应方的专业版完整流程没有据此获得验证。

Codex 默认使用 `workspace-write` 沙箱和 `on-request` 批准策略。工作区目录不是独立的权限隔离机制；主动附带的内容也不等于 CLI 可访问的全部内容。CLI 仍加载自己的项目配置和 hooks。支持双向权限的适配器会展示真实请求；不支持的接口不会被包装成可继续批准的交互。

## 查看结果与验证

“变化与验证”按每次执行保存记录：

- 执行状态和 Agent 的说明分别保存。Agent 正常结束仍显示“尚未验证”。
- 文件变化比较任务开始前和结束采集时的工作区。已有未提交及未跟踪内容作为基线保留；不执行 Git reset、clean 或自动还原。
- 变化可能同时包含你的编辑或其他程序写入。历史差异固定，不会被后续编辑覆盖。
- 选择“构建工作区”或“验证工作区配置”，确认显示的 Core 操作及目录后运行。验证沿用当前桌面 Core 的任务、权限、日志和取消机制。
- 验证进行时，停止按钮控制验证任务，不改写原 Agent 终态。结束后继续修改文件，会提示重新验证。
- 可以导出当前运行的脱敏 JSON 记录。原生桥接将文件写到 `.copperbench/agent-chat/exports/`，显示保存路径并打开所在文件夹；文件内容、日志和原始供应方错误仍可能包含项目内部信息，导出范围显示在面板中。

文本基线最多记录 2,000 个文件、每文件 128 KiB、合计 4 MiB。排除 `.git`、`.gradle`、`.copperbench`、`node_modules`、`build`、`dist`、`output`、`run`、`logs`、`.idea`、符号链接及常见凭据文件。小型二进制文件记录哈希；超大文件记录大小和时间，范围受限时明确标为部分采集。没有可靠前像的文件不宣称为确定新增或删除。

## 取消、历史与限制

点击停止先进入“正在取消”，待协议及所属进程树清理后才确认取消。无法确认清理时保留中断状态，并阻止该项目新写入。服务异常退出也不会自动重放任务。记录中的 PID 和启动时间用于人工核对，不按进程名结束其他用户进程。

记录位于项目 `.copperbench/agent-chat/`，绑定规范目录与本机执行环境。移动项目后不自动恢复旧 CLI 会话；原记录保留。最多保存 100 次运行，达到上限后需整理归档记录。

当前没有自动安装、自动升级、自动回滚、远程执行、WSL/容器路径转换或同目录多个写入 Agent。设置 JVM 属性 `copperbench.agent.disabled=true` 可阻止新 Agent 任务；历史、取消和已经开始的任务仍可查看。
