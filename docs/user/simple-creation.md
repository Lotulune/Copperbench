# 简洁创作

简洁创作把同一工作区中的作品内容、对话、纹理预览和常用设置集中到一个界面。标题栏可随时切换到专业工作台；源码、Python 编辑器草稿和正在进行的助手任务不会因为切换而丢失。

## 开始一件作品

选择“新建作品”，填写名称并确认 Minecraft 版本和加载器。默认推荐现有首作流程使用的组合；加入已有整合包时，应选择与整合包一致的目标。模组标识和 Java 包名会自动生成，也可在“更多设置”中修改。新建使用现有工作区创建流程，不覆盖已有目录。

已有工程可通过“打开作品”选择 `.mcreator` 文件。作品在原工程上继续编辑。

未完成的新建表单会保留输入。创建成功后，可以点击“新建另一件作品”，或离开表单后再次选择“新建作品”，开始新的创建。

## 连接创作助手

可选择本机的 Codex CLI、Claude Code、Grok Build、Google Antigravity CLI 或 DeepSeek Harness。各助手名称前有品牌图标。每个对话固定使用一个后端；换后端会创建新的对话，原对话保留。

“重新检测”检查程序安装及版本，不代表账号已登录或模型服务已连通。未安装时，安装指引打开该工具的官方页面；登录入口打开该 CLI 自己的流程。完成后返回应用重新检测。首次实际发送消息时，认证、网络或执行环境错误会显示在对话附近。

DeepSeek Harness 使用官方 `dsh` 命令和本机已有配置。首次使用可按[官方指南](https://github.com/deepseek-ai/deepseek-harness)运行 `dsh web`，在 Settings → Models 中配置模型；应用中的“配置指南”会打开官方说明。它支持在对话中审批操作、停止任务，并在再次发送消息时恢复原生会话。

Antigravity 沿用它的权限设置。其非交互接口不能在对话中回传实时审批，未被允许的命令可能被拒绝；界面保留原因和处理指引，配置好所需权限后可重试。其他后端根据实际请求显示审批选项或澄清问题。Codex 默认使用工作区写入和按需批准。若在专业工作台为当前对话选择了只读沙箱或完全访问，简洁创作沿用该选择，并在输入框上方显示；可以点击“恢复默认权限”，或打开专业工作台查看。

澄清问题按助手提供的类型显示单选或多选；支持自定义回答时，可填写“其他回答”。选好后点击“提交回答”。操作审批仍由相应的允许或拒绝按钮处理。

## 创作、试玩和导出

描述想添加或修改的内容。助手通过当前桌面工作区的公共 SDK 读取实际生成器和字段合同，修改后执行构建并读取任务结果。对话展示进展；操作详情可展开查看。

右侧使用作品的真实纹理和设置，不是游戏内画面的替代。需要查看实际玩法时点击“在游戏中试玩”；“导出模组”沿用已有交付流程。构建通过不能替代游戏验证。

若专业工作台仍有未保存修改，试玩前会让你选择取消并应用修改，或试玩已保存内容。已移除内容留下的未应用设置会提供单独的丢弃入口，不影响其他内容的草稿。

“停止”中断助手执行并保留已发生的修改。已有工作区任务可在任务面板中查看和处理。“恢复点”打开项目原有历史流程，恢复范围及确认步骤与专业工作台一致。

## 离开和回来

最小化和模式切换不会停止助手。存在未结束的助手任务或未保存草稿时，退出会要求确认。关闭后保存对话记录并停止所属 CLI 进程；再次打开不会自动恢复执行，发送新消息后才继续。

未发送的聊天输入也属于未保存草稿。确认放弃并关闭后，这些文字不会保留。

对话记录保存在工作区的 `.copperbench/agent-chat/`。CLI 的原生会话记录和账号配置仍由各自工具管理。浏览器预览不具备执行主机 CLI 的能力。
