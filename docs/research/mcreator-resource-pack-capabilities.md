# MCreator 资源包与资产能力核查

- 调研日期：2026-08-16
- 核查目标：区分可直接继承的上游能力与值得新增的产品能力

## 已确认的上游能力

| 能力 | 核查结果 | 产品处理 |
| --- | --- | --- |
| 独立资源包工作区 | MCreator 2024.4 起提供，不依赖模组加载器 | 直接继承并纳入兼容测试 |
| 选择目标 Minecraft 版本 | 创建资源包工作区时选择 | 复用，并接入版本轨道策略 |
| 加载原版资源并建立覆盖项 | 官方工作流会加载原版资源，用户选择要覆盖的资源 | 直接继承 |
| 内置纹理编辑 | 双击覆盖项可进入内置纹理编辑器 | 不重写；只做必要的版本/引用增强 |
| 一键测试 | 启动测试客户端后自动加载并选中当前资源包 | 直接继承，并接入 MCP 验证和日志 |
| ZIP 导出 | 可导出可直接安装的资源包 ZIP | 直接继承，并补可重复构建信息 |
| 资源包生成器 | 上游仓库同时存在 1.21.1 与当前 26.1.x 稳定生成器 | 复用生成器结构并纳入四轨测试 |
| 模型动画 | 官方当前流程以 Blockbench 创建并导出实体动画 | 集成 Blockbench，不建设第二套动画器 |

## 不应重复开发

- 独立资源包项目壳与 ZIP 打包。
- 原版资源浏览和覆盖的基础流程。
- 基础像素纹理编辑器。
- 资源包测试客户端启动器。
- 通用模型、UV 和关键帧动画编辑器。

## 值得新增的差异化能力

- 资产版本历史、比较、回退和发布批次。
- Blockbench 资产往返及 `.bbmodel` 源文件关联。
- 模型、纹理、动画、语言和声音之间的引用关系图。
- 跨 Minecraft 版本的资源格式检查与迁移报告。
- Fabric/NeoForge 模组资源与独立资源包之间的复用、覆盖冲突检查。
- MCP 领域工具：导入、替换、引用检查、预览构建、启动测试和结果采集。
- 可重复测试：截图基线、游戏日志诊断、资源缺失与命名错误定位。

## 尚未确认

- 上游资源包工作区对声音、字体、着色器及任意自定义资源文件的 UI 覆盖深度。
- Blockbench 集成采用插件协议、文件监听、MCP 编排还是多种方式组合。
- 四条版本轨道各自支持的资源包格式迁移范围。

这些项目必须通过源码和实际运行样例核查，不能依据搜索摘要直接列为已支持。
