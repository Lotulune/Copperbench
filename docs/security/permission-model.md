# MCP 与自动化权限模型

权限档位定义技术边界，审批策略决定何时询问用户；两者不能互相替代。

## 三档权限

| 能力 | Read Only | Workspace | Full Access |
| --- | --- | --- | --- |
| 查询工作区、元素、资产、日志 | 允许 | 允许 | 允许 |
| 在临时快照中执行纯校验 | 允许 | 允许 | 允许 |
| 修改当前工作区 | 拒绝 | 允许 | 允许 |
| 创建恢复点和操作日志 | 强制 | 强制 | 强制 |
| 构建、导出、启动测试客户端 | 拒绝 | 允许 | 允许 |
| 读写工作区外普通文件 | 拒绝 | 拒绝或逐项批准 | 允许 |
| 网络访问 | 默认关闭 | 按操作和目标授权 | 允许，但受保护操作仍确认 |
| 启用 Java 插件 | 拒绝 | 受保护操作 | 受保护操作 |
| 删除工作区、导出凭据、外部发布 | 受保护操作 | 受保护操作 | 受保护操作 |

`Read Only` 校验如需生成临时文件，必须使用产品管理的临时快照，并在完成后清理；不得把 Gradle 缓存或生成文件写回工作区。

## 受保护操作

以下操作无论档位或 YOLO 设置如何都要求用户明确确认：

- 删除或不可逆覆盖工作区。
- 导入、显示、复制或导出凭据。
- 发布到 Modrinth、CurseForge、Git 远端或其他外部平台。
- 启用或更新含 Java 代码的插件。
- 放宽监听地址、关闭认证或允许远程 MCP。

## 本机 MCP 传输

- 只绑定回环地址，不绑定 `0.0.0.0`。
- 每个工作区会话生成独立、短期、不可写入项目历史的随机令牌。
- 拒绝通配 CORS；只允许产品配置的客户端来源或不使用浏览器 CORS 流程。
- 日志记录客户端标识、工具、参数摘要、结果、修订号和恢复点，不记录完整凭据。
- 工作区关闭、权限变化或超时后吊销令牌。
- 请求必须携带工作区标识，不能用一个令牌跨工作区操作。

## 不可关闭的安全能力

- Schema 校验与领域校验。
- 单写者锁与修订冲突检查。
- 变更操作日志。
- 变更前恢复点策略。
- 受保护操作确认。
- 凭据脱敏。

## 威胁场景

| 场景 | 必需行为 |
| --- | --- |
| 恶意网页扫描 localhost | 无令牌无法初始化或调用工具；CORS 不放行 |
| 两个 AI 客户端同时修改元素 | 一个事务成功，另一个收到修订冲突 |
| YOLO 删除整个工作区 | 仍触发受保护操作确认 |
| Java 插件版本被替换 | 哈希变化后重新确认信任 |
| Blockbench 请求工作区外路径 | 资产桥拒绝并返回范围错误 |
| 构建日志包含令牌 | 日志管道脱敏后再展示或持久化 |
